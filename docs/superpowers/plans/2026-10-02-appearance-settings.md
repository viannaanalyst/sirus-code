# Appearance settings implementation

Implement the approved preview through existing settings and primitives. No GUI control or new preview generation. This checkout has no Git metadata; use source snapshots for review rather than initializing a repository.

## Global constraints

- Exactly Dark, Light and Translucent modes. Translucent is neutral smoked glass with no nested light/dark selector. Dark/Light optionally enable sidebar glass independently. All Settings and app surfaces participate; floating controls must not turn opaque black in Translucent.
- UI → Client → Transport → Rust boundary remains unchanged. Extend existing save_settings/host_info, not the IPC allowlist. Native appearance accepts closed enums and bounded integers only, never paths, URLs, image bytes or CSS from the renderer. Native effects run on the main thread and saved preferences apply on startup and after saving.
- Dock choices are default and smokedGlass. Embed existing src-tauri/icons/icon.png and approved previews/appearance/dock-icons/smoked-glass.png. Do not generate or expose rejected silver/white replacement artwork.
- Use existing Arc dropdowns, compact Orbit switches, UI typography roles, motion preferences and Zustand. One Restore defaults action restores Appearance keys only.
- Fields/schema: theme dark|light|translucent (legacy system migrates dark); darkSidebarTranslucent=false; lightSidebarTranslucent=false; darkSidebarOpacity=72; lightSidebarOpacity=38; translucentOpacity=85; opacity bounds 25–100 integers. systemUiFont=true; uiFont=inter; uiFontSize=13 with bounds11–18. codeFont=plexMono; codeFontSize=13 with bounds10–22. terminalFont=plexMono; terminalFontSize=13 bounds10–22. fontSmoothing=true; dockIcon=default. Existing glass stays a deprecated boolean for compatibility, not a visible toggle. Existing density/motion/composer controls remain.
- Closed UI font IDs: inter, geist, dmSans, plexSans, humanist, helvetica. Closed mono IDs: plexMono, jetbrains, fira, geistMono, source, roboto, ubuntu, sfMono, menlo, cascadia, hack, consolas. Curated non-system font assets are bundled with licenses, no remote product font loading. Installed-only options explain fallback. System UI override preserves chosen UI family for later.
- HostInfo appearanceSupport={translucency:boolean,dockIcon:boolean}; macOS true, other platforms false. Unsupported UI disables native-only controls and uses opaque readable fallback, never claims desktop glass.
- No Computer Use or live app launch. Fresh npm typecheck/lint/test/build and Rust fmt/check/clippy/test, Graphify incremental update, signed desktop build verification. Native visual finish remains unverified without launch.
