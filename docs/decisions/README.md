# Architecture Decision Records

An ADR records a decision that was expensive to make, would be expensive to reverse, and whose reasoning is not visible from the source. It answers **why the system is like this**.

These are not a changelog. Overturned decisions get a new ADR; the old one is marked `Superseded by ADR-XXX` and never deleted.

## Template

```markdown
# ADR-XXX: Title

**Status:** Proposed | Accepted | Deprecated | Superseded by ADR-YYY

## Context

What problem existed, and what constraints applied.

## Decision

What was decided, stated directly, and where in the code it lives.

## Consequences

- **Positive:**
- **Negative:**
- **Accepted trade-off:**

## Alternatives considered

What else was tried or rejected, and why.
```

## When to write one

Write an ADR when a change constrains future work, is expensive to reverse, or resolved something that was measured or argued about (IPC, agents, Git, persistence, remote). Skip naming, colours, and patch bumps.
- [ADR-094: Working panel beside the composer](ADR-094-working-panel.md) — at two or more sessions in flight, a card at the bottom-right beside the composer (bottom-left until ADR-136, which also lets it fold into an edge tab) lists each with its provider, project icon, title, current step and time; waiting ones first; a switch in Chat behavior turns it off. ⌘J is removed.
- [ADR-095: Files pane keyboard navigation and text search](ADR-095-files-pane-keyboard-and-text-search.md) — the file tree is an ARIA tree with roving focus, arrows/Home/End/Page keys and typeahead; a magnifier opens a text search (ripgrep, else Git's file list, else a bounded walk) whose results open the editor at the line.
- [ADR-096: One entrance for menus and popups](ADR-096-one-popup-entrance.md) — popup boxes enter with a soft scale (160 ms, from 96%, on keyframes Radix starts once positioned) and leave with a 100 ms fade; their rows follow with the sidebar cascade (capped at ten steps) only on open, never while typing.
- [ADR-097: Claude background subagents keep their turn](ADR-097-claude-background-subagents.md) — when Claude answers while subagents it launched with `run_in_background` still run, the turn keeps its process (up to 30 minutes), reads the CLI's follow-up turns into the same reply, and ends when none remains; a strip above the composer lists them with a stop each, timeline rows show their state, and interrupted ones can be resumed.
- [ADR-098: Glass window opening, left-to-right reveal](ADR-098-glass-window-opening.md) — the main window is created hidden, gets its glass (or opaque) appearance natively and is shown on the first ready paint (`window_ready`, 2.5 s fallback, Dock reopen); the launch logo splash is gone; the content wipes in from the left while the rail, header and main area slide in after it.
- [ADR-099: Native transcripts on demand and dirty-only saves](ADR-099-native-transcripts-on-demand.md) — the Rust process loads only active and the 6 most recently used transcripts (others stay as counts in `state.json` and are read when a path needs them, outside the lock); saves write only loaded transcripts changed since their last write, so a settings or draft save writes `state.json` alone and an unloaded transcript is never written; search reads at most the 400 most recent sessions from disk without keeping them.
- [ADR-100: Native process hygiene for agents, Git and GitHub reads](ADR-100-native-process-hygiene.md) — Codex MCP tokens go through the Codex environment and `env_vars`, never argv; native Git runs with `GIT_OPTIONAL_LOCKS=0`, status counts lines with `diff-index` and lists at most 2000 untracked files; Stop and Quit also kill agent descendants that left the process group (SIGTERM, SIGKILL after 1.5 s); a power assertion keeps the Mac awake while any turn runs; agent CLIs run at nice +5; every `gh` read shares a gate (5 at once, 60 s pause after a rate limit, 10 s reuse).
- [ADR-101: Visible subagent replies, a Stop that stops, kept handoffs and the live thought](ADR-101-subagent-replies-stop-handoff-thought.md) — a marker where each background subagent finished keeps its reply visible; Stop marks the session stopped by the person (PR watch and CI auto-fix wait for the next send) and cascades to sessions it launched; a handoff recap is spent only once the prompt was taken; the live row shows the first sentence of the latest thought, never stored.
- [ADR-102: Workspace UX batch](ADR-102-workspace-ux-batch.md) — typing reaches the composer only from non-interactive focus and only the visible main composer; glass terminals keep the theme color at zero alpha (transparency only on glass); diff rows are memoized and diffs get their own ⌘F find bar; ⇧⌘T reopens the last closed header tab, dock pane or browser tab from one bounded stack; PR bodies render as Markdown with https images in the gallery.

- [ADR-169: Diffs render with @pierre/diffs](ADR-169-diffs-render-with-pierre.md) — Pierre highlights in workers, virtualizes and pins file headers; our find, line selection, comments, copy and cache stay; the own highlighter, windowing and document code are removed. - [ADR-170: Terminal on Ghostty's VT core](ADR-170-terminal-on-ghostty-vt.md) — xterm.js is replaced by `libghostty-vt` in WebAssembly drawn on a canvas, ported from t3code (MIT) with Ghostty's license and a symbols-only Nerd Font; the Sirus palette, glass transparency (ADR-102), fonts, links, selection, paste and IME carry over; production CSP allows `wasm-unsafe-eval`.
- [ADR-171: Animated icon swaps and optional agent sounds](ADR-171-animated-icons-and-optional-sounds.md) — copy, sidebar and expand toggles cross-fade their icons (instant with reduced motion); `agentSounds` (off by default) plays soft Web Audio tones when a turn finishes or an agent needs input, never for the conversation in view.
- [ADR-172: Tasks and scheduled tasks removed](ADR-172-tasks-and-scheduled-tasks-removed.md) — the owner retired the Tasks page, scheduled and webhook-triggered tasks: their modules, commands, events, rail item, remote `/hooks` route and the eight agent MCP tools are gone, and schema v7 drops the `tasks` and `scheduled_tasks` tables. Supersedes ADR-051, 052, 110, 142 and 161.
- [ADR-173: Conversation archive removed](ADR-173-conversation-archive-removed.md) — no Archive action, Archived page or auto-archive; on load, conversations saved as archived are deleted through the same path as Delete conversation (`archive_removal.rs`), releasing a clean worktree only when the old release setting was on. Supersedes the archiving parts of ADR-029, 078, 086, 089, 124, 129, 130 and 132.
