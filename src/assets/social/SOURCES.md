# Share marks

Bundled Simple Icons SVG marks, CC0 (see LICENSE.md). Decorative share controls
use these local assets, with no runtime network asset loading.

- X and Reddit: `simple-icons/simple-icons`, release `14.0.0`, `icons/x.svg` and
  `icons/reddit.svg`.
- LinkedIn: release `11.0.0`, `icons/linkedin.svg` (removed from later releases).

Source: https://github.com/simple-icons/simple-icons
