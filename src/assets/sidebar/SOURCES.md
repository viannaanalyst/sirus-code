# Sidebar glyph sources

The two unmodified Central reversed folder SVGs are the exact assets used by
Synara’s `FolderClosed.tsx`: `folder-2` and `folder-open-front`.
Copied from the owner’s local Synara checkout on 2026-10-01 at their request.
The same CSS-mask rendering preserves their single uniform outline and inherits
the host text color. No remote icon loading or full icon pack is included.

Reference: `synara/apps/web/public/central-icons-reversed/` and
`synara/apps/web/src/components/FolderClosed.tsx`.
The reference checkout’s MIT notice is retained in `SYNARA-LICENSE`.
