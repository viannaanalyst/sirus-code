# Sirus Code brand assets

- `public/sirus-glyph.png` is the transparent silver "S" orbit mark used by the
  New thread landing and the launch splash.
- `public/sirus.svg` embeds the 128 px desktop icon for browser favicons and
  the composer preview.
- `src-tauri/icons/` contains the desktop/platform icon sizes and the embedded
  Dock alternatives. How the Dock tiles are derived from the owner's mark is in
  [`public/dock-icons/README.md`](../../public/dock-icons/README.md); see
  [ADR-067](../../docs/decisions/ADR-067-sirus-code-rebrand.md).
